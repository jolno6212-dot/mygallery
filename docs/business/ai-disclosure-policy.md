# AI利用の開示ポリシー

**この事業における最大のリスクは、技術的失敗ではなく規約違反による信用の喪失。**

クラウドソーシング上の案件には「AI利用禁止」「AI利用は要申告」「AI生成物は不可」という規定が案件ごとにバラバラに存在し、特にライティング領域に集中している。違反した場合、納品後トラブル・報酬未払い・アカウント停止に直結する。**評価アカウントは再取得できない資産**なので、グレーゾーンには踏み込まない。

---

## 基本原則

1. **偽らない。** AI利用の有無を問われたら正直に答える。嘘をついて受注した案件は、発覚時に全報酬を失うだけでなくアカウントごと失う。
2. **売っているのはAI出力ではなく、検証済みの成果物と責任。** これが正しい説明であり、後ろめたさを持つ必要もない。
3. **判断に迷ったら受けない。** 1件の案件より、アカウントの方が価値が高い。

---

## 成果物タイプ別の判断

AIの扱いは成果物の種類によって社会的な受け止め方が大きく異なる。同じ基準を全部に適用しない。

### A. コード・スクリプト・自動化ツール → 開示不要（道具として扱う）

IDE・補完・ライブラリと同様、**開発ツールの使用**と解釈されるのが一般的。個別に問われない限り自発的な申告は不要。

**ただし以下は必ず確認する:**
- [ ] 募集要項にAI利用の禁止・申告要求が書かれていないか
- [ ] クライアントから提供されたコードを外部に送信することが契約上禁止されていないか（→ `delivery-workflow.md` の秘密情報区分）
- [ ] 生成コードのライセンス上の問題がないか（既知のOSSコードとの一致がないか）

**該当:** GAS、VBA、スクレイピング、データ処理、Webツール、Androidアプリ改修 — つまり **Tier A のほぼ全て**。

### B. 文章・記事・コンテンツ → 明示的な許可がない限り受けない

この領域はAI利用への忌避感が強く、規約も厳しい。

| 募集要項の記載 | 対応 |
|---|---|
| AI利用禁止・AI生成物不可 | **受けない**（STEP 1 で即時除外） |
| AI利用は要申告 | 提案文で明示的に申告し、承諾を得てから着手 |
| AI利用OK・歓迎 | 受注可。品質検証は通常どおり実施 |
| **記載なし** | **提案文で自分から申告する**。返答がない／曖昧なら辞退 |

**「記載がないからセーフ」とは考えない。** 文章成果物では記載なし＝暗黙に人力を期待されているケースが多い。

### C. 翻訳・要約・データ抽出 → 申告した上で受注

事実の正確性が問われるため、**検証工程を必ず明示する**。「AIで下訳を作り、全文を人力で検証しています」という説明は、むしろ品質保証の説明として機能する。

## 申告が必要な場合の文面テンプレート

### 提案時の申告

```
なお、作業効率化のためAI支援ツール（Claude 等）を制作工程で使用しております。
生成物をそのまま納品することはなく、全ての成果物について私自身が動作検証・
事実確認を行った上で納品いたします。成果物の品質および内容については、
私が責任を負います。

AI支援ツールの使用可否についてご指定がございましたら、
着手前にお知らせいただけますと幸いです。
```

### 使用可否を問われた場合

```
はい、制作工程でAI支援ツールを使用しております。
ただし成果物は生成結果をそのまま納品するものではなく、
以下の工程を経ております。

・仕様との突き合わせ
・実際に動作させての検証
・（該当する場合）事実関係の裏取り

品質と内容の責任は私が負いますので、ご懸念の点がございましたら
遠慮なくお申し付けください。
```

### 禁止案件だった場合の辞退

```
恐れ入りますが、今回のご要件を拝見し、私の作業体制では
ご期待に沿えないと判断いたしました。
このたびは見送らせていただきます。

ご検討いただきありがとうございました。
```

**理由を詳細に説明する必要はない。** 簡潔に辞退するのが最も安全。

---

## 絶対にやらないこと

- ❌ AI利用禁止と明記された案件を、バレないと判断して受注する
- ❌ 使用可否を問われて虚偽の回答をする
- ❌ 検証していない生成物をそのまま納品する
- ❌ クライアントの秘密情報を、契約上の制約を確認せずAIに投入する
- ❌ 「AIを使っていない」ことを前提とした実績・スキルの誇張をプロフィールに書く

---

## 受注前チェック（提案送信ボタンを押す前に）

- [ ] 募集要項全文をAI関連キーワードで確認した（「AI」「ChatGPT」「生成」「自動生成」「ツール」）
- [ ] クライアントのプロフィール・過去の募集内容も確認した
- [ ] 成果物タイプ（A/B/C）を判定した
- [ ] B または C の場合、申告文を提案に含めた
- [ ] 秘密情報の取扱区分を判定した（→ `delivery-workflow.md`）

## 四半期ごとの再確認

プラットフォームの利用規約とAI関連ポリシーは改定される。**3か月に1回**、以下を確認して本ドキュメントを更新する。

- ランサーズ / クラウドワークス / ココナラ の利用規約とAI関連のヘルプページ
- 各社が提供するAI機能の商用利用条件
- 使用しているAIサービス側の利用規約（生成物の権利・商用利用条件）
